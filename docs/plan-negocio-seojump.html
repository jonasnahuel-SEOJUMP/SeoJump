1. Resumen ejecutivo

SEO Jump es una plataforma gamificada de SEO y AEO para PyMEs y agencias en LATAM. La propuesta central: resultados accionables, no reportes técnicos.

Conclusiones clave:
  • El modelo freemium (2 gratis → pago) es viable y rentable.
  • Costos de infra bajos con límites por usuario (~USD 1–5/cliente pagador en Gemini).
  • Las claves AQ. de Google funcionan; el error 429 es cuota, no clave inválida.
  • Un fundador solo puede sostener 50–100 usuarios con ayuda de IA.
  • Supabase ya tiene subscription_status listo para cobro.

8. Validación de mercado (30 días)

  1. Resolver mínimo técnico (clave Vercel, créditos Gemini).
  2. Publicar fixes locales pendientes.
  3. Conseguir 3–5 testers de negocios reales (LATAM).
  4. Documentar caso 55detailshop como éxito.
  5. Medir: ¿vuelven la semana siguiente?
Criterio: Si 2 de 3 testers vuelven → implementar cobro y límites. Si nadie vuelve → replantear mensaje, no abandonar por costos técnicos.

Conectá tu WordPress con SEO Jump para aplicar título SEO y meta descripción con un clic.

== Description ==

SEO Jump Connector permite que la app SEO Jump escriba en tu sitio **solo** el título SEO y la meta descripción de la página que vos elijas, cuando tocás «Aplicar en mi web».

No modifica productos, precios, stock ni el diseño.

== Installation ==

1. Subí el ZIP en WordPress → Plugins → Añadir nuevo → Subir plugin.
2. Activá «SEO Jump Connector».
3. Andá a Ajustes → SEO Jump y pegá el token de SEO Jump (Perfil → Conectar WordPress).
4. En SEO Jump tocá «Verificar conexión».

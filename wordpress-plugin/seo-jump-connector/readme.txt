Conectá tu WordPress con SEO Jump para aplicar título SEO y meta descripción con un clic.

== Description ==

SEO Jump Connector permite que la app SEO Jump escriba en tu sitio el **título SEO** y la **meta descripción** de la página, producto o **categoría** que elijas, cuando tocás «Aplicar en mi web».

Requisitos:
* WordPress 5.8+
* Yoast SEO o Rank Math (para guardar título/meta sin tocar el nombre del producto)

No modifica precios, stock ni el diseño del tema.

== Installation ==

1. Subí el ZIP en WordPress → Plugins → Añadir nuevo → Subir plugin.
2. Activá «SEO Jump Connector».
3. Ajustes → SEO Jump → pegá el token de SEO Jump (Perfil → Conectar WordPress).
4. En SEO Jump tocá «Verificar conexión».
